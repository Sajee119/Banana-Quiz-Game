# Sound effects

These clips come from the **Sound Effects** category on
[Myinstants](https://www.myinstants.com/en/categories/sound%20effects/gb/).
They were downloaded on 2026-11-13 and renamed after the game event they play
for. The `manifest.js` file maps each game event to the bundled audio clip.

| File             | Plays for                          | Myinstants source                                                                 |
| ---------------- | ---------------------------------- | --------------------------------------------------------------------------------- |
| `click.mp3`      | UI clicks and navigation           | [TF2 Button Click](https://www.myinstants.com/en/instant/tf2-button-click-91464/)  |
| `correct.mp3`    | Correct answer, coin, save success | [ding sound effect](https://www.myinstants.com/en/instant/ding-sound-effect/)     |
| `wrong.mp3`      | Wrong answer                       | [Metal pipe clang](https://www.myinstants.com/en/instant/metal-pipe-clang-80894/) |
| `timeout.mp3`    | Time ran out                       | [dun dun dunnnnnnnn](https://www.myinstants.com/en/instant/dun-dun-dunnnnnnnn-68584/) |
| `game-over.mp3`  | Game over                          | [VINE BOOM SOUND](https://www.myinstants.com/en/instant/vine-boom-sound-70972/)   |
| `skip.mp3`       | Skipped question                   | [Звук фотоаппарата](https://www.myinstants.com/en/instant/zvuk-fotoapparata-61186/) |
| `notify.mp3`     | Notifications                      | [Discord Notification](https://www.myinstants.com/en/instant/discord-notification-38119/) |
| `countdown.mp3`  | Last 5 seconds of a question       | [Censor Beep 1](https://www.myinstants.com/en/instant/censor-beep-1/)             |
| `game-start.mp3` | A quiz run starts                  | [Hub Intro Sound](https://www.myinstants.com/en/instant/hub-intro-sound-55662/)   |
| `streak.mp3`     | Correct answer streak (3+)         | [CapCut explosion sound](https://www.myinstants.com/en/instant/capcut-explosion-sound-62266/) |
| `win.wav`        | Win, achievement, finished quiz    | [screaming and clapping](https://www.myinstants.com/en/instant/screaming-and-clapping-68694/) |

`win.wav` is a converted copy of the original MP3 download; `win-old.mp3` keeps
the unconverted source as a backup and is not loaded by the game.

## Licensing note

Myinstants hosts user-uploaded clips. Some of these effects may be subject to
third-party rights even though they are publicly downloadable. Review the
licensing for your distribution before publishing this game commercially, and
replace any clip you are not allowed to redistribute. The synthesized effects
in `../audioEngine.js` remain as fallbacks for events without a sample.
